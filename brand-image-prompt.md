Use the 16:9 version for the website hero/OG banner and the square version for social profile tiles.

## How to use

1. Generate the image with your preferred AI tool.
2. Save the result into `public/` in the project (e.g. `public/brand-banner.png`).
3. Tell Claude the filename — it will wire it into the hero section / Open Graph
   metadata / social preview image.

For the actual favicon and header/footer logo, your real photo will be used directly
(cropped into a circle) — no AI regeneration needed for that part.
